## 🚀 How to Run

Each file is a standalone Java program. To run any file:

```bash
# Compile
javac Arrays/7.LargestElement.java

# Run
java -cp Arrays A
```

> **Note:** Most files use `class A` as the class name. Make sure to compile from the correct folder.
